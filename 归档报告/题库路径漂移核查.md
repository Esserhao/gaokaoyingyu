# 题库路径漂移核查

## 结论

问题属实。网站当前不是读取 `data/exams/`，而是读取 `data/index.json` 中 `file` 字段指定的年份目录副本。

`data/index.json` 中的路径形如：

```text
../2022/全国甲卷（全国）/gk2022-jia.json
```

由于索引文件位于 `data/` 目录，浏览器请求 `data/../2022/...` 实际解析为项目根目录下的：

```text
2022/全国甲卷（全国）/gk2022-jia.json
```

## 核对结果

| 试卷 | 索引实际加载位置 | 与 data/exams 是否一致 |
|---|---|---|
| 2023 全国乙卷 | `2023/全国乙卷（全国）/gk2023-yi.json` | 否 |
| 2023 全国甲卷 | `2023/全国甲卷（全国）/gk2023-jia.json` | 否 |
| 2023 新课标Ⅰ卷 | `2023/新课标Ⅰ卷（新高考地区）/gk2023-xkb1.json` | 是 |
| 2023 新课标Ⅱ卷 | `2023/新课标Ⅱ卷（新高考地区）/gk2023-xkb2.json` | 是 |
| 2022 全国乙卷 | `2022/全国乙卷（全国）/gk2022-yi.json` | 否 |
| 2022 全国甲卷 | `2022/全国甲卷（全国）/gk2022-jia.json` | 否 |
| 2022 新高考Ⅰ卷 | `2022/新高考Ⅰ卷（新高考地区）/gk2022-xgk1.json` | 是 |

共有 4/7 套题库存在内容漂移；其中 `data/exams/` 版本通常更大且更新时间更晚。

## 影响

在没有修正索引前，网站、整卷模拟和相关专题通过 `data/index.json` 加载的仍是年份目录版本。因此在 `data/exams/` 中做的结构化解析改进，对这 4 套试卷不会自动生效。

此前“7 套题库 JSON 可解析”和“自动质量审计通过”只能说明被审计的文件可解析，不能证明网站实际使用的副本就是最新副本。

## 当前处理原则

本次只完成核查，没有擅自覆盖或删除任一副本。下一步必须先确定唯一权威副本，再统一 `data/index.json` 的 `file` 字段或将已确认版本同步过去，并重新做逐文件审计和页面抽查。
