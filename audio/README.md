# 听力音频说明

本目录存放高考英语听力音频，命名规范：`listening-{年份}-{卷型}.mp3`。

| 文件 | 对应试卷 | 时长规模 | 来源 |
|------|----------|----------|------|
| listening-2021-jiayi.mp3 | 2021 全国甲卷 / 全国乙卷（两卷共用同一段听力） | 约 9.2MB | E:\Desk\题目\2021全国高考甲卷英语（有听力） |
| listening-2021-xgk1.mp3 | 2021 新高考Ⅰ卷 | 约 9.2MB | E:\Desk\题目\2021全国新高考1卷英语( 含听力) |
| listening-2021-xgk2.mp3 | 2021 新高考Ⅱ卷 | 约 10.5MB | E:\Desk\题目\2021年汇编目录 |

## 使用状态

- 2021 年各卷**尚未导入题库**，音频为提前备货；导入 2021 卷后在对应 JSON 中将 `hasAudio` 置为 `true`，并在 `audio` 字段指向本目录相对路径。
- 2022/2023 年七套已导入试卷暂无音频素材，`hasAudio` 保持 `false`；在补齐音频前，听力题只能以文字稿对照方式降级使用。
- 甲乙卷共用音频：全国甲卷与全国乙卷 2021 年听力材料相同，两个 JSON 的 `audio` 字段可指向同一文件。

## 注意

- 音频文件仅本地使用，不随网站公开发布（版权考虑）。
- 如需给 2022/2023 卷补音频，从原始材料获取后按同样命名规范放入本目录。
